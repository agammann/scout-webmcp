# Using Scout

Scout is a fictional card comparison lab. The sample is fixed at August 29, 2026 and never represents live market prices.

Start with `Ember Dragon ex`, choose **CGC 10**, and click **Search market**. Two matching listings appear. Inspect each one's item-plus-known-shipping total, seller evidence, exact sale history, and score breakdown. Add both to Compare to see the evidence side by side.

Try a $500 maximum, minimum trust of 90, and minimum discount of 5%. One sample listing remains: `listing-hf-1042` at $425.00. Clear those criteria or choose a sample-search shortcut before exploring another card.

Searches use keywords. `Volt Lynx PSA 10` is supported; `find the best card under $500` is an instruction for a compatible browser agent to translate into tool fields, not text to put in the keyword box.

The raw-versus-graded section includes all tiers for the selected card. It does not pool conditions, grading companies, numeric grades, currencies, or variants. Compare scores relate to each listing's own market evidence.

No result means no matching sample listing. No old selection is left on screen. At five selected listings, add buttons disable until a selection is removed. Reloading clears the page's selections.

Use the header's tool status to check WebMCP availability. A compatible host can call the six tools described in the README. Without that API, manual browsing, filtering, and comparison still work.
